# Amigo Secreto 🎁

Este es un proyecto de sorteo de Amigo Secreto desarrollado en HTML, CSS y JavaScript.

## Funcionalidades ✨
- Permite agregar nombres de participantes.
- Evita nombres duplicados mediante una alerta.
- Realiza el sorteo de manera aleatoria.
- Muestra los resultados del sorteo en pantalla.
- Reinicia el juego automáticamente tras finalizar el sorteo.
- Cambia los colores del diseño de forma aleatoria dentro de una paleta predefinida.

## Tecnologías Utilizadas 🛠️
- **HTML**: Estructura de la página.
- **CSS**: Estilización y diseño responsivo.
- **JavaScript**: Lógica del sorteo y gestión de la interfaz.

## Uso 🚀
1. Ingresar los nombres de los participantes.
2. Hacer clic en "Añadir" para agregarlos a la lista.
3. Presionar "Sortear amigo" para realizar el sorteo.
4. Visualizar los resultados y esperar el reinicio automático.
